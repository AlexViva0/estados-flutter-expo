Código · estado efímero

Mostrar u ocultar la contraseña

bool mostrar = false; // estado efímero
TextField(
  obscureText: !mostrar,
  decoration: InputDecoration(
    suffixIcon: IconButton(
      icon: Icon(mostrar ? Icons.visibility
                       : Icons.visibility_off),
      onPressed: () => setState(() {
        mostrar = !mostrar;
      }),
    ),
  ),
)

Día 1 · Bloque 1 · [Expositor 1]

Estado efímero: temporal, vive mientras existe el widget y se maneja con setState(). Leer el código de arriba abajo: la variable mostrar es el estado; obscureText depende de ella; al tocar el ícono, setState cambia el valor y Flutter vuelve a dibujar el campo. Nadie más en la app necesita saber si la contraseña se ve, por eso no hace falta Provider ni nada externo. DEMO PROPIA: tener este código corriendo en el emulador y tocar el ojo en vivo.
