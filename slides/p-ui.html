Una vista por cada estado

BlocBuilder<EstudiantesCubit, EstudiantesState>(
  builder: (context, state) => switch (state) {
    EstudiantesInicial() => const Text('Presiona el botón para comenzar'),
    EstudiantesCarga() => const CircularProgressIndicator(),
    EstudiantesVacio() => const Text('No hay estudiantes registrados'),
    EstudiantesError(:final mensaje) => Text(mensaje), // + botón Reintentar
    EstudiantesExito(:final estudiantes) => ListView.builder(
        itemCount: estudiantes.length,
        itemBuilder: (_, i) => ListTile(title: Text(estudiantes[i].nombre),
            subtitle: Text(estudiantes[i].correo))),
  },
)

El switch con patrones (Dart 3) obliga a cubrir los cinco estados gracias a sealed. (:final mensaje) extrae el dato del estado. En el documento completo, el estado Error lleva un ícono rojo y un botón Reintentar que vuelve a llamar a cargarEstudiantes(), y un FloatingActionButton.extended “Cargar estudiantes” llama al Cubit con context.read. main.dart: MaterialApp con home: BlocProvider(create: (_) => EstudiantesCubit(const EstudianteService()), child: const EstudiantesPage()). Para probar cada estado: Éxito con internet; Error en modo avión; Vacío con EstudianteService(simularVacio: true). En una versión release de Android, agregar el permiso INTERNET en AndroidManifest.xml.
