4.2 · StatefulWidget

El ciclo de vida del State

El widget se reconstruye muchas veces; el objeto State sobrevive y conserva los datos.

B

StatefulWidget no es una biblioteca externa: es la pieza base del framework. Explicar con la animación: createState una vez; initState una vez (aquí se crean un TextEditingController, un AnimationController o un Timer); build muchas veces; dispose al final (aquí se liberan; si no, hay fugas de memoria). Pregunta al grupo: “¿Dónde pondrían la llamada a la API para cargar datos al abrir la pantalla: en build o en initState?” Respuesta: en initState, porque build se repite.
