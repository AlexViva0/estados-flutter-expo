4.2 · StatefulWidget

El ciclo de vida del State

El widget se reconstruye muchas veces; el objeto State sobrevive y conserva los datos.

B

StatefulWidget no es una biblioteca externa: es la pieza base del framework. Explicar con la animación (un ciclo dura unos 18 segundos): abajo a la izquierda está el objeto State y a la derecha la pantalla. createState una vez; initState una vez (aquí se crean un TextEditingController, un AnimationController o un Timer); build muchas veces; dispose al final (aquí se liberan; si no, hay fugas de memoria). Señalar el contador “×N” bajo build(): la pantalla se redibuja varias veces, pero el objeto State es el mismo y conserva el valor. Pregunta al grupo: “¿Dónde pondrían la llamada a la API para cargar datos al abrir la pantalla: en build o en initState?” Respuesta: en initState, porque build se repite.
