Contador en tres piezas

1 · La lógica

class ContadorCubit extends Cubit<int> {
  ContadorCubit() : super(0);
  // ↑ estado inicial

  void aumentar() => emit(state + 1);
  void reiniciar() => emit(0);
}

No sabe nada de botones ni de pantallas.

2 · Proveer y 3 · dibujar

BlocProvider(
  create: (_) => ContadorCubit(),
  child: BlocBuilder<ContadorCubit, int>(
    builder: (context, n) => Text('$n'),
  ),
)

// en el botón:
context.read<ContadorCubit>().aumentar();

Día 2 · Bloque 6 · [Expositor 6]

Relacionar con lo de ayer: BlocProvider funciona como ChangeNotifierProvider (y por dentro, como InheritedWidget); BlocBuilder es como context.watch: se reconstruye con cada estado nuevo; context.read sirve para llamar métodos desde un botón. DEMO PROPIA: correr el contador con Cubit y agregar en vivo un botón “reiniciar”. Instalación: flutter pub add flutter_bloc.
