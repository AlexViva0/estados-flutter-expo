Dos tipos de widget

¿Recuerda algo o no?

StatelessWidget

No guarda datos propios que cambien. Dibuja lo que recibe.

class Saludo extends StatelessWidget {
  const Saludo({super.key});

  @override
  Widget build(BuildContext context) =>
      const Text('Hola');
}

StatefulWidget

Guarda datos que cambian en un objeto State.

class Contador extends StatefulWidget {
  State<Contador> createState() =>
      _ContadorState();
}
class _ContadorState
    extends State<Contador> {
  int visitas = 0; // ← el estado
}

A

StatelessWidget: interfaz que no mantiene un estado mutable propio; si cambia lo que recibe, el padre lo vuelve a crear. StatefulWidget: el widget en sí es inmutable, pero crea un objeto State que sí guarda los datos que cambian y que sobrevive a las reconstrucciones. Pregunta rápida al grupo: “¿Un ícono de la app sería Stateless o Stateful?” (Stateless). “¿Una casilla que se marca?” (Stateful).
