El Cubit decide qué estado emitir

class EstudiantesCubit extends Cubit<EstudiantesState> {
  final EstudianteService _servicio;
  EstudiantesCubit(this._servicio) : super(const EstudiantesInicial());
  Future<void> cargarEstudiantes() async {
    emit(const EstudiantesCarga());
    try {
      final datos = await _servicio.obtenerEstudiantes();
      emit(datos.isEmpty
          ? const EstudiantesVacio()
          : EstudiantesExito(datos));
    } catch (e) {
      emit(const EstudiantesError('No se pudieron cargar los datos.'));
    }
  }
}

F

El Cubit recibe el servicio por el constructor (inyección de dependencias: así se puede pasar un servicio falso en las pruebas). El estado inicial es EstudiantesInicial. cargarEstudiantes emite Carga, espera al servicio y, según el resultado, emite Vacío, Éxito o Error. En el documento de la práctica viene también un método reiniciar() que emite Inicial. El mensaje de error es amable y no muestra detalles técnicos al usuario.
