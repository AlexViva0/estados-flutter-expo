Cuatro formas de leer un Provider

Forma¿Se reconstruye?Dónde usarla
watch<T>()Sí, ante cualquier cambioDentro de build
read<T>()NoEn onPressed y callbacks
select<T, R>()Solo si cambia esa propiedadPantallas con muchos datos
Consumer<T>Solo la parte de su builderRedibujar un pedazo pequeño

Ventajas: menos datos pasados a mano y curva de aprendizaje accesible.

Cuidado: una clase con demasiadas tareas se vuelve difícil de mantener.

C

Ejemplo de select: context.select<Carrito, int>((c) => c.cantidad) hace que el widget solo se reconstruya cuando cambia la cantidad y no cuando cambia otra cosa del carrito. Consumer sirve para envolver solo el Text que cambia y no toda la pantalla. Dónde se aplica Provider: apps pequeñas y medianas, formularios, catálogos y datos compartidos.
