Código · setState()

El contador clásico

class _ContadorState extends State<Contador> {
  int contador = 0;
  @override
  Widget build(BuildContext context) {
    return Column(children: [
      Text('Contador: $contador'),
      ElevatedButton(
        onPressed: () {
          setState(() { contador++; });
        },
        child: const Text('Incrementar'),
      ),
    ]);
  }
}

Ventajas

Fácil, integrado, sin dependencias.

Desventajas

Si muchos widgets comparten el dato, la pantalla acumula demasiada lógica.

Dónde se usa

Contadores, casillas, selección de opciones, formularios sencillos.
