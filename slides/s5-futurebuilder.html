7.1 · FutureBuilder

Los cinco estados en un solo widget

FutureBuilder<List<String>>(
  future: _futuro,                                              // inicial
  builder: (context, snapshot) {
    if (snapshot.connectionState == ConnectionState.waiting) {
      return const CircularProgressIndicator();                  // carga
    }
    if (snapshot.hasError) return const Text('Ocurrió un error');      // error
    final lista = snapshot.data ?? [];
    if (lista.isEmpty) return const Text('No hay estudiantes');       // vacío
    return ListView(children: [
      for (final n in lista) ListTile(title: Text(n)),         // éxito
    ]);
  },
)

E

Recorrer el código con los comentarios naranjas: cada rama del builder es uno de los cinco estados. snapshot trae el estado de la conexión, los datos o el error. obtenerEstudiantes() es una función propia que devuelve un Future de lista de String. Ventaja: integrado, sin gestor de estados completo. Desventaja: si varias pantallas comparten la operación, conviene moverla a un servicio o a un gestor como Cubit (bloque 6). DEMO PROPIA: correrlo con un Future.delayed de 2 segundos para que se vea el círculo de carga, y luego lanzar una excepción para mostrar el error.
