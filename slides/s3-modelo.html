El modelo: datos + operaciones

class Carrito extends ChangeNotifier {
  final List<String> _items = [];
  List<String> get items => List.unmodifiable(_items);
  int get cantidad => _items.length;

  void agregar(String producto) {
    _items.add(producto);
    notifyListeners(); // avisa a quien escucha
  }

  void vaciar() {
    _items.clear();
    notifyListeners();
  }
}

Esta clase no sabe nada de la interfaz: solo guarda datos y tiene operaciones. Eso es “separar la lógica de la interfaz”. Puntos a remarcar: la lista es privada (guion bajo), así que la única forma de cambiarla es con agregar() o vaciar(); el getter devuelve una lista no modificable; cada operación termina con notifyListeners().
