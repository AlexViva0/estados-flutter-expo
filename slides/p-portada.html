Consulta de estudiantes con Cubit

Un botón consulta una API real y la pantalla muestra los cinco estados

flutter create practica_estudiantes

cd practica_estudiantes

flutter pub add flutter_bloc http equatable

Dirige el Expositor 6 y el resto del equipo pasa por los lugares a ayudar (así nadie se queda atrás y se cumple el control de grupo). Requisitos: Flutter instalado (flutter doctor), un emulador o celular, e internet (se usa la API pública JSONPlaceholder). Paquetes: flutter_bloc trae Cubit y BlocBuilder; http llama a la API; equatable compara estados por valor y evita reconstrucciones innecesarias. Repartir el documento de la práctica con el código completo.
