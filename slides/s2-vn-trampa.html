Más allá del temario · error común

Cambiar la lista por dentro no avisa

✗ La pantalla no se entera

final lista =
  ValueNotifier<List<String>>([]);

// misma lista, mismo objeto
lista.value.add('Ana');

✓ Asigna una lista nueva

final lista =
  ValueNotifier<List<String>>([]);

// objeto distinto → notifica
lista.value = [...lista.value, 'Ana'];

ValueNotifier solo avisa cuando le asignas a value algo distinto al valor anterior. La misma idea aplica en Provider, BLoC y Cubit: estado nuevo, objeto nuevo.

Día 1 · Bloque 2 · [Expositor 2]

Este es un punto “más allá del temario” que el docente valora. ValueNotifier compara el valor nuevo con el anterior; si haces add() sobre la misma lista, el objeto es el mismo y no se dispara la notificación. La solución es crear una lista nueva con el operador spread (...). Es la base de la inmutabilidad que veremos mañana en Cubit con equatable.
