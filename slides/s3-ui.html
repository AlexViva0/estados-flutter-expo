Proveer arriba, usar abajo

1 · En main.dart, arriba de todo

void main() {
  runApp(
    ChangeNotifierProvider(
      create: (_) => Carrito(),
      child: const MiApp(),
    ),
  );
}

2 · En cualquier widget de abajo

// escucha: se reconstruye
final n = context.watch<Carrito>().cantidad;
Text('Carrito: $n');

// solo actúa: no se reconstruye
ElevatedButton(
  onPressed: () => context
      .read<Carrito>().agregar('Gorra'),
  child: const Text('Agregar'),
)

C

DEMO PROPIA: mostrar el carrito funcionando en el emulador con dos pantallas (catálogo y resumen) y navegar entre ellas: el número se conserva porque el Carrito vive arriba de las dos. Regla práctica: watch dentro de build para mostrar datos; read dentro de callbacks como onPressed para ejecutar acciones. Usar watch dentro de onPressed provoca un error en tiempo de ejecución.
